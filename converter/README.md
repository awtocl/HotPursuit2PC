# converter

The deliverable of the brief's §3: a small Windows program that validates the
user's ROM folder, organises everything inside one `game/` folder next to its
own `.exe`, converts, and leaves a build that runs without the converter.

| Piece | Phase | Status |
|---|---|---|
| `core/` — ROM validation, `game/` layout, stages, resume, logs | P3 | pending |
| `cli/` — same operations, headless | P3 | pending |
| `gui/` — Win32 front-end (ADR 0003) | P3 | pending |
