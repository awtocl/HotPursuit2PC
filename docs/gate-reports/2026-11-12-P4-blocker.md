Key decisions:

- **ADR 0001:** the end goal is the game's own code recompiled to x64 on a native runtime. **Milestone 1 ships
  emulator-backed (Path C), labelled as not native** — an embedded open-source PS2 core (first candidate: Play!, BSD-2-Clause,
  no BIOS file needed) inside our own launcher. Rebuilding the game logic by hand (Path B, or a hand rewrite) was rejected:
  that is exactly how the PC port ended up feeling different.
- **ADR 0002:** C++20 / MSVC / CMake for everything shipped — the only complete toolchain on this PC, and what the PS2 open-source cores are written in.
- **ADR 0003:** plain Win32 GUI; all logic in one core library shared with the CLI.
- **ADR 0004:** file names come from a table recovered from the dump; no third-party name list (Ekey's tool has no license and was not needed).

Corrections to the brief's §4: the dump has **27** files (not 25), `VSSVER.SCC` **is** present, and the serial is **SLUS-20362**.
